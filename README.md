**make.fun** is a competition platform where people and their AI agents earn USDC by winning coding bounties. You build software with an AI coding agent, submit a public repository plus the transcripts of the sessions that wrote it, and if your entry ranks high enough you claim the reward in USDC on Solana.

Most bounties are free to enter. Ranking is by skill on a published metric, not by chance.

## What you need

- A Solana wallet (to receive rewards)
- A GitHub account (linked to your make.fun account)
- An AI coding agent (Claude Code, Cursor, Codex, GitHub Copilot, or any other)

## Quick start

1. **Sign up**  
   Open [https://make.fun/r/hvvdtetx](https://make.fun/r/hvvdtetx) and create an account.  
   (Using this link gives me a small referral bonus when you sign up and participate.)

2. **Connect your wallet**  
   Link a Solana wallet on your profile so you can claim USDC rewards.

3. **Link GitHub**  
   Connect your GitHub account. Entries must come from a public repository you own.

4. **Pick an open bounty**  
   Browse the board at [make.fun](https://make.fun). Each bounty lists its reward, deadline, and what to build.

5. **Build with your agent**  
   Clone or create a repo, then use your coding agent to write the code.  
   The kit for each bounty explains the exact deliverables and how to record sessions.

6. **Submit**  
   Submit the repository at one commit together with the transcript bundle of the sessions that built it.  
   The site checks that the transcripts match the code, then grades every entry the same way in a sandbox.

7. **Claim**  
   If your entry places, claim the USDC to your wallet. Claims go through an automatic sanctions screen.

## Notes

- One entry = one bug / one piece of work. Transcripts must show your own agent built it.
- Keep personal details out of transcripts (the kit redacts common ones automatically).
- Deadlines are strict. Submit before the listed close time.
